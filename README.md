# Highly Available Web Application on AWS

## Project Overview
This project demonstrates how to deploy a highly available web application using AWS infrastructure.

## AWS Services Used
- Amazon EC2
- Amazon VPC
- Public and Private Subnets
- Internet Gateway
- Route Tables
- Security Groups
- Elastic Load Balancer
- Amazon CloudWatch
- Apache Web Server

## Architecture
1. Created a custom VPC.
2. Configured public and private subnets.
3. Configured route tables and Internet Gateway.
4. Launched Linux EC2 web servers.
5. Installed and configured Apache.
6. Configured an Elastic Load Balancer to distribute traffic.
7. Used CloudWatch to monitor AWS resources.
